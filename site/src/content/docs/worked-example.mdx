This walkthrough takes the path with the strongest evidence: the agent lets a small share of conversations try a random option. The [home page](/) shows the same agent left unchanged, with agentope asking the model again instead.

A support team runs an agent on {example.meta.model}, served with vLLM. Every command and output on this page is real agentope output, produced by [`examples/support_agent/run.py`](https://github.com/liminalplanes/agentope/tree/main/examples/support_agent). The traces are simulated, so the true answer is known and you can see whether agentope gets it right.

## The question

At the start of every conversation, the model chooses one of four first moves: search the knowledge base (`search_kb`), look up the order (`lookup_order`), hand over to a person (`escalate_to_human`), or answer directly (`__none__`).

The team suspects a plain rule would resolve more tickets: **look up the order whenever the customer gives an order number, and search the knowledge base otherwise.** An A/B test would take weeks of live traffic. They want an answer from conversations they already have.

## Log a little exploration

One change to the agent: wrap the first move in `agentope.explore`. In {percent(example.meta.epsilon)} of conversations it takes a random option from the three the team is happy to take at random. It never hands over to a person at random, because people are expensive. The coin flip is recorded on the model's span; the other {percent(1 - example.meta.epsilon)} run exactly as before.

## Read the result

Under the rule, **{percent(r.estimates.snips, 1)} of tickets would have been resolved, against {percent(r.estimates.logging_mean, 1)} today**: {points(r.estimates.difference)} more, with a 95% interval from {signed(lo)} to {signed(hi)}.

- The interval is clear of zero, so the improvement isn't noise.
- It rests on the {count(r.diagnostics.n)} explored conversations; their effective sample is {count(Math.round(r.diagnostics.ess))}.
- The rule only picks options the exploration also took, so there are no support violations.
- The one assumption to think about: only the first move changes, and later turns go as they did.

Because the traces are simulated, the true difference is known: **{signed(example.truth.lookup_difference)}**, inside the interval.

## What this example doesn't cover

- **It evaluates one decision.** Later turns are assumed to go as logged. To compare a whole new agent, choose the agent per conversation with `agentope.randomize`, so the outcome reflects everything it does.
- **It tests a rule, not a new prompt.** For a prompt or model change, capture message content and let agentope ask the model again: see [Sampling the model](/docs/sampling).
